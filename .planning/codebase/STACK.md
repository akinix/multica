**Connection:** `pgx/v5` driver with connection pooling (`pgxpool`).

**Query layer:** sqlc-generated Go code from SQL in `server/pkg/db/queries/`. Generated output at `server/pkg/db/generated/`.

**Key query files:**

**Migrations:** `server/internal/migrations/migrations.go` with `server/cmd/migrate/` runner. Run via `make migrate-up` / `make migrate-down`.

**Local development:** Docker Compose (`docker-compose.yml`) runs `pgvector/pgvector:pg17` on port 5432. All checkouts share one PostgreSQL container; worktrees get isolated DBs.

**Redis:** Optional but supported for multi-instance realtime relay (`server/internal/realtime/redis_relay.go`). Uses `redis/go-redis/v9`. Required env: `REDIS_URL`. CI runs Redis 7 Alpine.
