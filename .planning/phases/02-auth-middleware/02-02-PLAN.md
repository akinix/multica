**Objective:** Implement cookie-based authentication with CSRF protection, Google OAuth login flow, and CloudFront signed cookie/URL generation.

<action>
Create `server/src/Multica.Core/Auth/CookieService.cs`:
- Constants: `AuthCookieName = "multica_auth"`, `CsrfCookieName = "multica_csrf"`
- `SetAuthCookies(HttpResponse response, string token)` — sets both cookies
  - Auth cookie: HttpOnly=true, Secure=from FRONTEND_ORIGIN scheme, SameSite=Strict, Path="/"

```json
    "FrontendOrigin": "http://localhost:3000"
  }
}
```
</action>

### Task 2.2: CSRF Validator

<read_first>
- server/internal/auth/cookie.go (Go reference: generateCSRFToken, ValidateCSRF)
- server/src/Multica.Core/Auth/TokenHasher.cs (crypto patterns)
</read_first>

<action>
Create `server/src/Multica.Core/Auth/CsrfValidator.cs`:
- `GenerateCsrfToken(string authToken) → string`
  - Generate 16 random bytes (nonce)
  - HMAC-SHA256(nonce, authToken) → signature
  - Return `hex(nonce) + "." + hex(signature)`
- `ValidateCsrf(HttpRequest request) → bool`
  - Skip for GET/HEAD/OPTIONS (return true)
  - Read `X-CSRF-Token` header
  - Read `multica_auth` cookie
  - Split on "." → nonce + signature
  - Verify HMAC-SHA256(nonce, cookieValue) == signature
  - Use `CryptographicOperations.FixedTimeEquals` for timing-safe comparison
</action>

<acceptance_criteria>
- CSRF token format matches Go: `hex(nonce).hex(hmac)`
- Validation skips safe methods (GET, HEAD, OPTIONS)
- Validation rejects missing header, missing cookie, invalid signature
- Timing-safe comparison prevents timing attacks
- Unit test: generate → validate succeeds; tamper → validate fails
</acceptance_criteria>

### Task 2.4: CloudFront Signer

<read_first>
- server/internal/auth/cloudfront.go (Go reference: RSA-SHA1 signing, cookie generation)
- server/src/Multica.Core/Auth/CookieService.cs (cookie patterns)
</read_first>

<action>
Create `server/src/Multica.Core/Auth/CloudFrontSigner.cs`:
- Constructor: `CloudFrontSigner(string keyPairId, RSA privateKey, string domain, string cookieDomain)`
- `FromConfigurationAsync(IConfiguration config, ISecretsManagerClient? secretsClient) → Task<CloudFrontSigner?>`
  - Returns null if CLOUDFRONT_KEY_PAIR_ID not set
  - Loads private key from: AWS Secrets Manager (CLOUDFRONT_PRIVATE_KEY_SECRET) → env var fallback (CLOUDFRONT_PRIVATE_KEY, base64-encoded PEM)
  - Parses PKCS8 then PKCS1
- `SignedCookies(DateTime expiry) → List<CookieHeaderValue>`
  - Policy: `{"Statement":[{"Resource":"https://{domain}/*","Condition":{"DateLessThan":{"AWS:EpochTime":{epoch}}}}]}`
  - CloudFront base64 encoding: `+` → `-`, `=` → `_`, `/` → `~`
  - Signs with RSA-SHA1 (PKCS1v15)
  - Returns 3 cookies: CloudFront-Policy, CloudFront-Signature, CloudFront-Key-Pair-Id
  - Cookie attributes: Domain=cookieDomain, Path="/", Secure=true, HttpOnly=true, SameSite=None
- `SignedURL(string resourceUrl, DateTime expiry) → string`
  - Same policy/signing, returns URL with query params

Config keys:
```json
{
  "CloudFront": {
    "KeyPairId": "",
    "Domain": "static.multica.ai",
    "PrivateKeySecret": ""
  }
}
```
</action>

<acceptance_criteria>
- CloudFront base64 encoding matches Go: `+` → `-`, `=` → `_`, `/` → `~`
- RSA-SHA1 signature matches Go output for same key/policy
- Returns null when CLOUDFRONT_KEY_PAIR_ID not set (disabled)
- Private key loaded from Secrets Manager or env var fallback
- Cookie attributes match Go: Secure, HttpOnly, SameSite=None
- Unit test with known key/policy/expected signature
</acceptance_criteria>

Register endpoints in Program.cs with `app.MapGroup("/api/auth")`.
</action>
