Create RuntimeLivenessStore.cs in namespace Multica.Infrastructure.Redis (per D-05, D-06, D-07, D-08):

Interface IRuntimeLivenessStore with: bool Available, Task TouchAsync(string runtimeId, TimeSpan ttl), Task<Dictionary<string, bool>> IsAliveBatchAsync(IEnumerable<string> runtimeIds), Task ForgetAsync(string runtimeId).

Class RedisRuntimeLivenessStore implementing IRuntimeLivenessStore. Inject IConnectionMultiplexer. Key prefix "mul:runtime:hb:". TouchAsync does StringSet with TTL. IsAliveBatchAsync uses StringGet with batch keys. ForgetAsync deletes key. Available checks _redis.IsConnected.

Class NoopRuntimeLivenessStore implementing IRuntimeLivenessStore. All methods return defaults (Available=false, TouchAsync=noop, IsAliveBatchAsync=empty dict, ForgetAsync=noop). Used when Redis is unavailable.

Create RuntimeModelListStore.cs (per D-09, D-10, D-11, D-12):

Interface IRuntimeModelListStore with: Task<string> InitiateListAsync(string runtimeId, TimeSpan timeout), Task<(string Status, object? Models)> GetResultAsync(string runtimeId, string requestId).

Class RedisRuntimeModelListStore. Key pattern "mul:runtime:models:{runtimeId}:{requestId}". InitiateListAsync stores a pending entry with TTL (5 min). GetResultAsync checks if result exists (populated by daemon callback). Uses JSON serialization for model data.

Create RuntimeUpdateStore.cs:

Interface IRuntimeUpdateStore with: Task<string> InitiateUpdateAsync(string runtimeId, JsonDocument? payload, TimeSpan timeout), Task<(string Status, object? Response)> GetResultAsync(string runtimeId, string updateId).

Class RedisRuntimeUpdateStore. Same pending-request pattern as model list store. Key pattern "mul:runtime:update:{runtimeId}:{updateId}".

Register all three stores in DI via AddInfrastructure extension method. Use AddSingleton for stores. Include noop fallback registration when Redis connection string is missing.
