Implement POST /api/agents/from-template -> CreateAgentFromTemplate handler.

CreateAgentFromTemplate implementation (per D-15, Pitfall 6):
- Parse request: { template_slug, name, description, runtime_id, runtime_mode, visibility, model, thinking_level }
- Find template by slug in workspace
- Return 404 if template not found
- Validate name is not empty
- Parse runtime_id, validate exists in AgentRuntimes

Skill deduplication (per Pitfall 6 - two-phase dedup):
1. Pre-flight check: look up existing skills by cached_name in workspace before fetching template skills
2. For each template skill reference: find existing skill by name in workspace
3. If skill exists: reuse existing skill (create AgentSkill join only)
4. If skill doesn't exist: create new Skill from template reference

Transaction:
- Create Agent entity with template fields as defaults (per D-15):
  - Name from request (or template name if not provided)
  - Description from request (or template description)
  - Instructions from template
  - Model from request (or template model)
  - RuntimeMode from request (or template runtime_mode)
  - RuntimeConfig from template
  - CustomArgs from template
  - McpConfig from template
  - Status="active", Visibility from request (or "private")
- Create AgentSkill joins for each resolved skill
- Save in transaction
- Return AgentResponse with skills populated

Register route: POST /api/agents/from-template in the agent group.
