Register routes matching Go exactly:
- GET /api/agents -> ListAgents
- POST /api/agents -> CreateAgent
- POST /api/agents/from-template -> CreateAgentFromTemplate
- GET /api/agents/{id} -> GetAgent
- PUT /api/agents/{id} -> UpdateAgent
- POST /api/agents/{id}/archive -> ArchiveAgent
- POST /api/agents/{id}/restore -> RestoreAgent

Use app.MapGroup("/api/agents") for agent routes. Register static routes (/api/agent-templates) separately.

ListAgents implementation:
- Extract workspaceId from HttpContext.Items["WorkspaceId"]
- Query agents where WorkspaceId matches, order by CreatedAt desc
- Batch-load skills for all agents in ONE query (avoid N+1 per Pitfall 1): query AgentSkills with Include Skill, group by AgentId in memory
- Convert to AgentResponse using ToResponse helper
- For agent actors (X-Agent-ID header present), call RedactMcpConfig on response

CreateAgent implementation:
- Validate name is not empty
- Parse runtime_id from request, validate it exists in AgentRuntimes
- Set defaults: Status="active", Visibility="private" if not provided, MaxConcurrentTasks=1 if not provided
- Generate new Guid for Id, set CreatedAt/UpdatedAt to.UtcNow
- If template_slug provided in CreateAgentFromTemplateRequest, load template and populate fields
- Save to DB, return AgentResponse

GetAgent implementation:
- Parse id as Guid, query agent by Id and WorkspaceId
- Return 404 if not found
- Load skills for this agent
- Apply mcp_config redaction for agent actors

UpdateAgent implementation (per Go's PUT semantics):
- Parse id as Guid, find agent
- Check canManageAgent (owner/admin or agent owner)
- Update only fields that are present in request body (thinking_level tri-state: omitted=no change, empty string=clear, value=validate and set)
- Set UpdatedAt = UtcNow
- Save and return AgentResponse

ArchiveAgent implementation (per AGT-02):
- Find agent, check not already archived
- Set ArchivedAt = UtcNow, ArchivedBy = userId from X-User-ID header
- Cancel all queued/dispatched/running tasks (set Status="cancelled", CompletedAt=UtcNow)
- Save in transaction, return AgentResponse

RestoreAgent implementation:
- Find agent, check is archived
- Clear ArchivedAt and ArchivedBy
- Save, return AgentResponse

CancelAgentTasks:
- Find agent, cancel all active tasks
- Return count of cancelled tasks

Register MapAgentEndpoints in Program.cs after existing endpoint registrations.
