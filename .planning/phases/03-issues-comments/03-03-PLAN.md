Add SearchIssues endpoint to IssueHandler.cs:

1. **SearchIssueResponse DTO** — Extend IssueResponse with search metadata:
   - match_source: "title" | "description" | "comment"
   - matched_snippet: optional string (120 chars centered on match)
   - matched_description_snippet: optional string
   - matched_comment_snippet: optional string

2. **Endpoint**: `GET /api/issues/search?q={query}&limit={20}&offset={0}&include_closed={false}`

3. **Search Logic** (per D-01, D-03):
   - Build LINQ query dynamically based on search terms
   - Search title and description using EF.Functions.ILike (case-insensitive LIKE)
   - For multi-word queries: each term must appear somewhere (AND logic per D-02)
   - Also search comment content via subquery
   - Parse query for issue number patterns (e.g. "MUL-123" or bare "123")

4. **Ranking Logic** (matching Go's tiered ranking):
   - Tier 0: Number exact match
   - Tier 1: Exact title match
   - Tier 2: Title starts with query
   - Tier 3: Title contains query
   - Tier 4: Title matches all words (multi-word)
   - Tier 5: Description contains query
   - Tier 6: Description matches all words
   - Tier 7: Comment contains query
   - Tier 8: Comment matches all words
   - Sort by rank, then status priority (in_progress > in_review > todo > blocked > backlog > done > cancelled)

5. **Snippet Extraction** — Extract ~120 chars centered on match for display

6. **Response Format**:
   ```json
   {
     "issues": [...],
     "total": 42
   }
   ```
   Header: X-Total-Count

Add ListIssues and ListGroupedIssues endpoints to IssueHandler.cs:

1. **ListIssues Endpoint**: `GET /api/issues?status={}&priority={}&assignee_id={}&creator_id={}&project_id={}&open_only={false}&limit={100}&offset={0}&sort={position}&direction={ASC}`

   Filter parameters (per D-02, all combine with AND):
   - status: exact match
   - priority: exact match
   - assignee_id: UUID filter
   - assignee_ids: comma-separated UUIDs
   - creator_id: UUID filter
   - project_id: UUID filter
   - involves_user_id: complex filter for agent/squad ownership
   - metadata: JSON object filter (JSONB @> containment)
   - open_only: exclude done/cancelled
   - scheduled: has start_date or due_date

   Sort parameters (per D-05):
   - sort: position, title, created_at, start_date, due_date, priority
   - direction: ASC, DESC (default ASC for position, ASC for others)
   - Priority sort: urgent > high > medium > low > none

   Response format:
   ```json
   {
     "issues": [...],
     "total": 42
   }
   ```

2. **ListGroupedIssues Endpoint**: `GET /api/issues/grouped?group_by={assignee}&statuses={}&priorities={}&assignee_types={}&sort={position}&direction={ASC}&limit={50}&offset={0}`

   Currently only group_by=assignee is supported.

   Response format (per Go):
   ```json
   {
     "groups": [
       {
         "id": "assignee:member:uuid",
         "assignee_type": "member",
         "assignee_id": "uuid",
         "issues": [...],
         "total": 5
       }
     ]
   }
   ```

   Group ID format: "assignee:{type}:{id}" or "assignee:unassigned" for null assignee

   Use EF Core LINQ for dynamic query building (per D-01).
