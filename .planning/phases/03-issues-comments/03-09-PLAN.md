   ```csharp
   public record SubscriberResponse(
       [property: JsonPropertyName("issue_id")] string IssueId,
       [property: JsonPropertyName("user_type")] string UserType,
       [property: JsonPropertyName("user_id")] string UserId,
       [property: JsonPropertyName("reason")] string Reason,
       [property: JsonPropertyName("created_at")] string CreatedAt
   );
   ```

2. **Endpoint Registration**: `MapSubscriberEndpoints(this WebApplication app)`

3. **ListIssueSubscribers Endpoint**: `GET /api/issues/{id}/subscribers`
   - Load issue
   - Query IssueSubscriber where IssueId matches
   - Return array of SubscriberResponse

4. **SubscribeToIssue Endpoint**: `POST /api/issues/{id}/subscribe`
   - Optional request body: { "user_id": "uuid", "user_type": "member" }
   - Load issue
   - Get actor from auth context (default target)
   - If user_id provided, use that instead
   - Create IssueSubscriber with reason "manual"
   - Return { "subscribed": true }

5. **UnsubscribeFromIssue Endpoint**: `POST /api/issues/{id}/unsubscribe`
   - Optional request body: { "user_id": "uuid", "user_type": "member" }
   - Load issue
   - Get actor from auth context (default target)
   - If user_id provided, use that instead
   - Delete IssueSubscriber
   - Return { "subscribed": false }

6. **Register in Program.cs**: Add `app.MapSubscriberEndpoints();`
