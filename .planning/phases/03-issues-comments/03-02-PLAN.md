Create `server/src/Multica.Api/Handlers/CommentHandler.cs` with the following structure:

1. **Response DTOs** — Create `CommentResponse` record matching Go's JSON format exactly:
   - All fields from Go's CommentResponse (id, issue_id, author_type, author_id, content, type, parent_id, created_at, updated_at, resolved_at, resolved_by_type, resolved_by_id, reactions, attachments)
   - reactions defaults to empty array (not null)
   - attachments defaults to empty array (not null)
   - Use `JsonPropertyName` attributes for snake_case JSON

2. **Request DTOs** — Create `CreateCommentRequest` record matching Go

3. **Endpoint Registration** — Static extension method `MapCommentEndpoints(this WebApplication app)`:
   - `GET /api/issues/{issueId}/comments` — ListComments (chronological, default behavior)
   - `POST /api/issues/{issueId}/comments` — CreateComment (requires auth)
   - `PATCH /api/comments/{commentId}` — UpdateComment (author or admin only)
   - `DELETE /api/comments/{commentId}` — DeleteComment (author or admin only, returns 204)

4. **ListComments Logic**:
   - Load issue by issueId (UUID or identifier)
   - Query comments for issue, ordered by CreatedAt ASC
   - Hard cap at 2000 comments (matching Go's commentHardCap)
   - For each comment, load reactions and attachments (empty arrays for now, wired in later plans)
   - Return 200 with array of CommentResponse

5. **CreateComment Logic**:
   - Load issue by issueId
   - Parse request body
   - Validate content is not empty
   - Default type to "comment" if not provided
   - Get author from auth context
   - If parent_id provided, validate parent comment exists and belongs to same issue
   - Create Comment entity with timestamps
   - Return 201 with CommentResponse

6. **UpdateComment Logic**:
   - Load comment by commentId
   - Check authorization: caller must be author or workspace admin/owner
   - Parse request body
   - Update content and UpdatedAt
   - Return 200 with CommentResponse

7. **DeleteComment Logic**:
   - Load comment by commentId
   - Check authorization: caller must be author or workspace admin/owner
   - Delete from database
   - Return 204 No Content

Use `MulticaDbContext` for all database operations. Inject via constructor or method parameters.
Use `[FromBody]` for request body binding.
Use `HttpContext.User` for auth context.
