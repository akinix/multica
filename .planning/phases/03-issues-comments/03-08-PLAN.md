   ```csharp
       [property: JsonPropertyName("id")] string Id,
       [property: JsonPropertyName("workspace_id")] string WorkspaceId,
       [property: JsonPropertyName("issue_id")] string? IssueId,
       [property: JsonPropertyName("comment_id")] string? CommentId,

       [property: JsonPropertyName("url")] string Url,
       [property: JsonPropertyName("download_url")] string DownloadUrl,
       [property: JsonPropertyName("content_type")] string ContentType,
       [property: JsonPropertyName("size_bytes")] long SizeBytes,
       [property: JsonPropertyName("created_at")] string CreatedAt
   );
   ```

2. **Endpoint Registration**: `MapAttachmentEndpoints(this WebApplication app)`

3. **ListIssueAttachments Endpoint**: `GET /api/issues/{id}/attachments`
   - Load issue
   - Query attachments where IssueId == issue.Id AND WorkspaceId matches
   - Return array of AttachmentResponse

4. **ListCommentAttachments Endpoint**: `GET /api/comments/{commentId}/attachments`
   - Load comment
   - Query attachments where CommentId == comment.Id AND WorkspaceId matches
   - Return array of AttachmentResponse

5. **Group Attachments Helper** (for ListComments):
   - Load attachments for multiple comment IDs
   - Group by comment_id
   - Return dictionary for attaching to CommentResponse

6. **Update GetIssue to include attachments**:
   - After loading issue, load attachments
   - Set resp.Attachments = attachments (empty array if none)

7. **Update ListComments to include attachments**:
   - After loading comments, bulk load attachments
   - Attach to each CommentResponse

8. **Register in Program.cs**: Add `app.MapAttachmentEndpoints();`
