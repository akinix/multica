Create `server/src/Multica.Api/Handlers/IssueHandler.cs` with the following structure:

1. **Response DTOs** — Create `IssueResponse` record matching Go's JSON format exactly:
   - All fields from Go's IssueResponse (id, workspace_id, number, identifier, title, description, status, priority, assignee_type, assignee_id, creator_type, creator_id, parent_issue_id, project_id, position, start_date, due_date, created_at, updated_at, metadata)
   - Identifier is computed as `{workspacePrefix}-{number}` (get prefix from workspace entity)
   - Metadata defaults to empty dictionary when null
   - Use `JsonPropertyName` attributes for snake_case JSON

2. **Request DTOs** — Create `CreateIssueRequest` and `UpdateIssueRequest` records matching Go

3. **Endpoint Registration** — Static extension method `MapIssueEndpoints(this WebApplication app)`:
   - `POST /api/issues` — CreateIssue (requires auth, workspace membership)
   - `GET /api/issues/{id}` — GetIssue (id can be UUID or identifier like "MUL-123")
   - `PATCH /api/issues/{id}` — UpdateIssue (partial update, nullable fields)
   - `DELETE /api/issues/{id}` — DeleteIssue (returns 204)

4. **CreateIssue Logic**:
   - Parse request body
   - Validate title is not empty
   - Resolve workspace from X-Workspace-ID header
   - Get creator from auth context (ClaimsPrincipal)
   - Default status to "todo", priority to "none" if not provided
   - Generate issue number via workspace counter (use DB sequence or max+1)
   - Create Issue entity with timestamps
   - Return 201 with IssueResponse

5. **GetIssue Logic**:
   - Parse {id} parameter — try UUID parse first, if fails try identifier parse (PREFIX-NUMBER)
   - For identifier: look up workspace prefix, query by (workspace_id, number)
   - For UUID: query by id
   - Return 404 if not found
   - Return 200 with IssueResponse

6. **UpdateIssue Logic**:
   - Parse {id} parameter (same as GetIssue)
   - Load existing issue
   - Apply partial updates — only set fields that are present in request body
   - Use JsonElement? to detect which fields were explicitly sent
   - Update UpdatedAt timestamp
   - Return 200 with IssueResponse

7. **DeleteIssue Logic**:
   - Parse {id} parameter
   - Load existing issue
   - Delete from database
   - Return 204 No Content

Use `MulticaDbContext` for all database operations. Inject via constructor or method parameters.
Use `[FromBody]` for request body binding.
Use `HttpContext.User` for auth context.
