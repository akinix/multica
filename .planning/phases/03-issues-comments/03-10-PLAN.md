   - If already resolved (ResolvedAt != null), return current state (no-op)
   - Get actor from auth context
   - Set ResolvedAt = DateTimeOffset.UtcNow
   - Set ResolvedByType = actor type
   - Set ResolvedById = actor id
   - Save changes
   - Return 200 with CommentResponse

2. **UnresolveComment Endpoint**: `POST /api/comments/{commentId}/unresolve`
   - Load comment by commentId
   - Validate comment is a root comment (ParentId == null)
   - If already unresolved (ResolvedAt == null), return current state (no-op)
   - Clear ResolvedAt, ResolvedByType, ResolvedById
   - Save changes
   - Return 200 with CommentResponse

3. **Helper: loadRootCommentForActor**:
   - Load comment by ID
   - Validate workspace access
   - Validate is root comment
   - Return comment, workspaceId, actorType, actorId
